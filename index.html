Overlay file

One self-contained .html file. Add it to OBS or Streamlabs as a Browser source.

  1. In OBS or Streamlabs Desktop, add a Browser source and tick Local file.
  2. Pick the saved file. Set width 1920, height 1080.
  3. Tick Refresh browser when scene becomes active so the countdown restarts each time.

For a vertical stream, also set your OBS canvas to 1080 × 1920 under Settings, Video.

Paste as a link

No file to keep track of. Paste this into the Browser source URL field. Overlays with uploaded images make a very long link, so use the file for those.
